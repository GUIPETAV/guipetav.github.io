# guipetav.github.io — Site Pessoal

Projeto pessoal desenvolvido por Guilherme Henrique Peterlini Tavares.

## Visão Geral

Site pessoal hospedado via GitHub Pages, reunindo atividade no GitHub e links de projetos.

## Estrutura do Repositório

| Arquivo | Descrição |
|---|---|
| `index.html` | Página inicial do site |
| `github-activities.html` | Página com atividades/contribuições no GitHub |
| `project-links.html` | Página com links para projetos |

## Como Usar

O site é publicado automaticamente pelo GitHub Pages a partir da branch principal — qualquer alteração enviada para o repositório atualiza o site em https://guipetav.github.io.

## Observações

Nome do repositório é fixo (exigência do GitHub Pages para sites de usuário) — não deve ser alterado.
